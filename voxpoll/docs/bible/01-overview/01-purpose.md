## Quick Summary

VoxPoll is an enterprise-grade SaaS polling platform combining:
- Individual user polling (B2C)
- Organization-managed surveys (B2B)
- Advanced gamification and reliability scoring
- Real-time live polling capabilities

**Target Users:**
- Individual users (free tier)
- Organizations (paid tiers with multi-seat management)
- Platform administrators

**Core Value Proposition:**
- Data quality through reliability scoring
- Fraud detection and prevention
- Gamified engagement system
- Unified responsive app (web + mobile)

---

## Architecture Philosophy

VoxPoll follows **Backend-First, API-First** architecture:
1. Backend and API contract completed first
2. Single responsive React app (web + mobile via React Native)
3. No separate "platform" app - organization features integrated into main app
4. Admin panel for internal team only

See [Architecture](./02-architecture.md) for technical details.

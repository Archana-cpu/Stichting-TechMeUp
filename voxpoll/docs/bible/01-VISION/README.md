## Quick Summary

### Mission
VoxPoll, veri kalitesi ve guvenilirligi on planda tutarak kamuoyu yoklamasi, anket ve kisilik testi platformu sunar.

### Core Values
1. **Data Quality First**: Her response'un kalitesi olculur
2. **Transparency**: Metodoloji ve sonuclar seffaf
3. **Accessibility**: Herkes icin kolay kullanim
4. **Privacy**: User data korumasi oncelikli

### Target Users
- B2C: Bireysel kullanicilar (poll olusturma, katilim)
- B2B: Organizasyonlar (employee surveys, market research)
- Belediyeler: Yerel yonetim anketleri

# 🎬 Sequences

A modern, full-stack application for managing emotional sequences and personal relationships.

## ⚡ Quick Start (One Command!)

```bash
pnpm start
```

That's it! This single command will:

- ✅ Check if Docker is installed
- 🐳 Start Docker Desktop automatically (if not running)
- 📝 Create `.env` file with secure defaults
- 🔨 Build Docker containers (only first time - ~2-3 min)
- 🚀 Start containers (subsequent runs - ~5-10 sec)
- 🗃️ Set up PostgreSQL database
- 🔄 Run migrations and seed data
- 🌐 Start the application at http://localhost:3000
- 🌍 Open your browser automatically

### Performance

- **First run**: ~2-3 minutes (building images)
- **Subsequent runs**: ~5-10 seconds (using cached images)
- **If already running**: ~2 seconds (instant!)

## 📋 Prerequisites

### Required
- **Node.js** >= 20.0.0
- **pnpm** 9.15.0
- **Docker Desktop**

### Installing Docker

#### Windows
```powershell
# Using winget (recommended)
winget install Docker.DockerDesktop

# Or download from: https://www.docker.com/products/docker-desktop
```

#### macOS
```bash
# Using Homebrew (recommended)
brew install --cask docker

# Or download from: https://www.docker.com/products/docker-desktop
```

#### Linux
```bash
# Ubuntu/Debian
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# Or visit: https://docs.docker.com/engine/install/
```

### Installing pnpm
```bash
npm install -g pnpm@9.15.0
```

## 🛠️ Development Commands

```bash
# Start everything (recommended) - FAST if already running!
pnpm start

# Stop all services
pnpm stop

# Restart services (without rebuild)
pnpm restart

# Rebuild and restart (after code changes)
pnpm rebuild

# View logs
pnpm logs

# Reset everything (including database)
pnpm reset

# Start with Docker (manual)
pnpm start:docker

# Start locally (requires local PostgreSQL)
pnpm start:local

# Development mode (web only)
pnpm dev:web

# Development mode (mobile only)
pnpm dev:mobile

# Run all tests
pnpm test

# Run E2E tests
pnpm test:e2e

# Database commands
pnpm db:studio      # Open Prisma Studio
pnpm db:generate    # Generate Prisma Client
pnpm db:push        # Push schema changes
pnpm db:seed        # Seed database
pnpm db:reset       # Reset database only
```

## 🌐 Environment Variables

The `.env` file is automatically created on first run with secure defaults:

```env
# Auth
AUTH_SECRET=<auto-generated>
AUTH_URL=http://localhost:3000
AUTH_TRUST_HOST=true

# Google OAuth (optional)
AUTH_GOOGLE_ID=
AUTH_GOOGLE_SECRET=

# Database (handled by Docker)
DATABASE_URL=postgresql://sequences:sequences@localhost:5432/sequences
DIRECT_URL=postgresql://sequences:sequences@localhost:5432/sequences
```

## 🆘 Troubleshooting

### Docker not starting?
```bash
# Windows: Make sure Docker Desktop is installed
winget list Docker.DockerDesktop

# Manually start Docker Desktop
# Then run: pnpm start
```

### Port 3000 already in use?
```bash
# Find and kill the process
# Windows:
netstat -ano | findstr :3000
taskkill /PID <PID> /F

# macOS/Linux:
lsof -ti:3000 | xargs kill -9
```

### Database connection issues?
```bash
# Reset everything
docker compose down -v
pnpm start
```
